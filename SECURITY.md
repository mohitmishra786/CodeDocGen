# Security Policy

## Supported Versions

The following versions of CodeDocGen are currently being supported with security updates:

| Version | Supported |
| :--- | :--- |
| 1.2.x | Yes |
| 1.1.x | No |
| < 1.1.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it privately. Do not disclose it through public issues or pull requests.

To report a vulnerability, please email mohitmishra786687@gmail.com with a detailed description of the issue and steps to reproduce it.

We aim to respond to security reports within 48 hours and provide a timeline for resolution.
